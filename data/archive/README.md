# Archived data

Notebook-era artefacts from the original restructure (`54539be`), referenced by
no script, test, or module. Kept for provenance.

- **`synthetic_validation_*.npz`** (5 files, one curve each) — hand-made
  single-curve synthetic checks from the notebook era. Superseded by
  `rheofp/data/synth.py`, which generates the full labelled population
  programmatically with planted parameters.
- **`likhtman_mcleish2002_fig11.npz`** — Fig. 11 of Likhtman–McLeish (2002).
  The tube-model validation uses Fig. 10 (`data/likhtman_mcleish2002_fig10.npz`);
  Fig. 11 was never wired into a validation.
- **`interpolated_rheology.npz`** — output of the notebook-era interpolation
  utility, now at `scripts/archive/prep_interpolate.py`.
