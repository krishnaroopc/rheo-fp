The result worth keeping

Zimm and rouse_screened are the same point. Their centroids sit 0.24 apart while the spread within each class is ~2.5 — a separation ratio of 0.095. For comparison, cured_elastomer and critical_gel sit at 2.220.

This is measured in all 128 dimensions, not read off a picture. It is independent evidence for what the project already claims on physical grounds: the Zimm↔Rouse confusion that accounts for 58% of remaining error is degeneracy in the data, not a decision boundary the network drew badly. There is no gap for a better boundary to occupy.

How much a 2-D picture can show you

Before any scatter: the first two components carry of the variance, and components are needed to reach 90%. So the projection below is a weak summary of a high-dimensional space — useful for spotting gross structure, not for judging whether two classes overlap.

Two things this contradicts

cured_elastomer ↔ critical_gel is not a degenerate pair here. At 3.85 raw distance it is the second-farthest pair in the entire matrix. AMBIGUOUS_PAIRS treats it as one class and merged_pair_accuracy collapses it — so part of the 0.968 merged figure is credit for a merge that isn't doing anything. That is consistent with the project's own measurement that the pair contributes zero errors, but it means the pair is listed for nested-model reasons the representation does not reflect.

branched ↔ star is the fourth-closest pair at 1.40, and it is not in AMBIGUOUS_PAIRS at all. The classifier does separate them (star scores 0.996), so the exclusion is defensible on its own terms — but the representation places them adjacent, which is exactly where the AICc side's documented failure lives: the 9-model bank silently absorbed 25/30 star melts into branched. Two independent methods, the same neighbourhood.

Why this is worth running at all

k-means never sees a label. If it independently groups the same classes the classifier confuses, that confusion is a property of the representation, not of the decision boundary — a second line of evidence that does not depend on the classifier being right about anything.

Choosing k

Inertia falls with every added cluster, so the question is where it stops falling fast. There is a visible step between k=6 and k=7; there is no sharp elbow at k=10, which is itself informative — the data does not naturally fall into ten equal groups.

What the clusters say

Three separate clusters are pure cured_elastomer (167, 196, 225 curves at purity 1.000 / 0.980 / 0.991). The unsupervised view splits one class into three groups rather than confusing it with anything — the opposite of a degeneracy problem. critical_gel and wormlike_micelle likewise get near-pure clusters of their own.

Cluster 4 is a 2304-curve pile-up at 0.295 purity, mixing sticky_reptation, zimm, reptation and rouse_screened. The terminal-flow classes collapse into one region — which is where the classifier's errors live too.

Cluster 6 mixes star (639) with branched (413) at 0.588 purity, and nothing else in quantity. The pairing found by distance in the previous tab reappears here, from an algorithm given no labels.

Do not over-read this

Agreement between clusters and labels is ARI = 0.381. That is well above chance (0 would be random) and far below a match (1.0). k-means assumes round, similar-sized clusters in a 128-dimensional space where neither holds, so treat it as corroboration of the centroid distances — not as an independent measurement of its own.

The centroid-separation table in the PCA tab is the artifact to quote. This tab's job is to show that an algorithm with no access to labels lands in the same places.
