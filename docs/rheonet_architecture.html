Model architecture · rheo-fp

RheoNet: a two-head set network for SAOS spectra

A permutation-invariant encoder over a variable-size stack of small-amplitude oscillatory-shear curves G′(ω), G″(ω), pooled by masked attention into one stack embedding that feeds a classification head (with learned abstention) and a parameter-regression head.

Training objective

L = CE(class) + 0.3 · CE(regime) + 0.2 · BCE(abstain, wrong) + 0.1 · SmoothL1(params)
  • The abstention target is argmax(class) ≠ label, detached — the head learns to predict the classifier's own errors without back-propagating into it.
  • Regime (terminal vs solid) is an auxiliary task, down-weighted; it is not the objective.
  • Head 2 targets are the planted parameter vectors, zero-padded to width 5 and masked by class so a 2-parameter model never trains the unused slots.
  • Split is by stack (70 / 15 / 15); normalisation statistics come from the training split only.
